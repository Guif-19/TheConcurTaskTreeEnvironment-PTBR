# TheConcurTaskTreeEnvironment-PTBR
Editor visual de árvores de tarefas ConcurTaskTree em português, com suporte a abrir, salvar, copiar, colar, recortar e desfazer no Windows.

Adaptação em português do protótipo The ConcurTaskTree Environment. A versão inclui interface traduzida, edição de tarefas, relações entre tarefas, abrir e salvar árvores, copiar/colar, recortar, desfazer/refazer e execução no Windows 10 ou superior. Baseada na revisão 35 do projeto original disponível no SourceForge, com aviso de procedência e licença original não localizada.
