# Avisos de terceiros

## Eclipse Compiler for Java (ECJ)

`tools/ecj-4.6.1.jar` é incluído somente para permitir a recompilação da adaptação com Java 8. Ele não é necessário para executar `classes-ptbr`.

- Artefato: `org.eclipse.jdt.core.compiler:ecj:4.6.1`
- Página do artefato: <https://repo1.maven.org/maven2/org/eclipse/jdt/core/compiler/ecj/4.6.1/>
- O compilador possui seus próprios termos de licença e avisos, que continuam aplicáveis.

Este aviso não altera os direitos do código e das imagens originais descritos em `ORIGINAL-SOURCE-NOTICE.md`.
